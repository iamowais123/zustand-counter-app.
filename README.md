# 🧮 Zustand Counter App

A simple **React Counter App** using **Zustand** for state management and **Tailwind CSS** for styling.  
Built to explore how Zustand makes global state simpler and cleaner than Redux ⚡

---

## 🚀 Live Demo
🔗 [View on Netlify](https://zustand-counter-app.netlify.app/)

---

## ⚙️ Tech Stack
- ⚛️ React  
- 🧩 Zustand  
- 🎨 Tailwind CSS  
- 🌐 Netlify  

---

## 🧠 Features
- Global state management with Zustand  
- Increase / Decrease count  
- Increase & Decrease by 5  
- Reset to 0  
- Fully responsive UI
